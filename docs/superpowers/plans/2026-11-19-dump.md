# Dump Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** `uv run dump [--db graph.db]` prints the live graph as sorted JSONL (nodes with `effective_tags`, then edges), read-only.

**Architecture:**
- `db/dump.py` reads the live views in one read transaction on a read-only connection.
- `api/dump.py` checks migrations and serialises the rows.
- `cli/dump.py` is the command.

The layer rules (`tests/test_layers.py`) apply.

**Tech Stack:** Python ≥ 3.11 stdlib, uv, pytest.

**Spec:** `docs/superpowers/specs/2026-11-19-dump-design.md`

## Global Constraints

- **Runtime:** stdlib only.
- **Commands:** every command runs as `uv run …`.
- **Git:** commit directly on `main`, and commit **only the files this plan names** (`git commit -- <paths>`). Another session is working on undo in the same tree.
- **README:** updated in the CLI task.
- **Line format:** `json.dumps(obj, sort_keys=True, separators=(",", ":"), ensure_ascii=False) + "\n"`.
- **Node keys:** `id, qualified_name, type, description, owner, tags, effective_tags`. **Edge keys:** `from_id, to_id, type`.
- **Order:** nodes first, sorted by `qualified_name`, then edges sorted by `(from_id, to_id, type)`. Python sorts the final lines again.
- **Exit codes:** 1, with no stdout, for a missing db, a non-SQLite file, pending migrations, or a db newer than the code. Otherwise 0.

## Review Focus

1. **Lock files:** a dump must not create or leave `-journal`/`-wal` files, and must not change the db's mtime. Test: `test_dump_is_read_only`.
2. **Non-ASCII names:** they sort the same as Python's `sorted`, and the output is UTF-8, not `\u` escapes. Test: `test_non_ascii_sort_and_encoding`.
3. **Mid-crash state:** a db with deleted rows and orphan-free live edges dumps no deleted rows and no dangling edges. Test: `test_no_dead_rows_no_dangling`.
4. **Empty graph:** no output and exit 0. Test: `test_empty_graph`.
5. **Pending migrations:** exit 1, and the db stays untouched (no migration is run). Test: `test_pending_migrations_refused`.

### Task 1: `live_graph` and `dump_lines`

**Files:**
- Modify: `src/graph_undo/db/connection.py`, adding `connect_readonly`.
- Create: `src/graph_undo/db/dump.py` and `src/graph_undo/api/dump.py`.
- Test: `tests/test_dump.py`.

**Interfaces produced:**
- `db.connection.connect_readonly(path) -> sqlite3.Connection`. It uses the URI `file:{path}?mode=ro` with `uri=True` and `isolation_level=None`.
- `db.dump.live_graph(con) -> tuple[list[dict], list[dict]]`. Node dicts have the seven node keys; `tags` and `effective_tags` are lists.
- `api.dump.DumpError(Exception)`.
- `api.dump.dump_lines(db_path) -> list[str]`. It raises `DumpError` for the exit-1 cases.

- [ ] **Step 1: Write the tests.** Use a small seed via `apply.conftest.BASE` and `load_seed`, and seed 42 via the generators.
  - `test_after_load_equals_seed`: the dump lines equal the seed's nodes, each with `effective_tags` added and computed by a Python ancestor walk, followed by the seed's edges, in dump order and serialised the same way.
  - `test_after_apply_equals_replay`: load and apply seed 42. Nodes by name equal `replay(...)` (type, description, owner, sorted tags). Each `contains` edge mapped to names equals `want.parent`, and the references equal `want.refs`. Every `effective_tags` equals an ancestor walk over the dumped edges.
  - `test_sorted_and_deterministic`: node lines are sorted by `qualified_name`, edge lines by `(from_id, to_id, type)`, and two dumps are equal.
  - `test_dump_is_read_only`: the db's bytes and `st_mtime_ns` are equal before and after, and no `g.db-journal` or `g.db-wal` file exists.
  - `test_no_dead_rows_no_dangling`: after applying `delete_node` on `conn/db/sc/t`, none of the subtree's ids appear, and every edge endpoint is a dumped node id.
  - `test_non_ascii_sort_and_encoding`: two nodes named `conn/é` and `conn/z` under a connection come out in Python `sorted` order. The line contains `é` literally.
  - `test_empty_graph`: an empty seed gives `[]`.
  - `test_errors`, parametrised over a missing file, garbage bytes, a db at `user_version` 1, and `user_version` 99. Each raises `DumpError`. For the version-1 case, `user_version` is still 1 afterwards.
- [ ] **Step 2: Run** `uv run pytest tests/test_dump.py -q`. Expected: collection ImportError.
- [ ] **Step 3: Implement.**
  - `live_graph` runs `BEGIN`, then two `SELECT`s, then `COMMIT`. Node rows come from `live_nodes` joined to `effective_tags` and are ordered by `qualified_name`. Edge rows come from `live_edges`, ordered.
  - `dump_lines` checks that the file exists, opens it with `connect_readonly`, and runs `db.migrate.pending` (refusing if anything is pending). It maps `MigrationError` and `sqlite3` errors to `DumpError`, serialises, sorts each group, and always closes the connection.
- [ ] **Step 4: Run** `uv run pytest -q`. Expected: everything passes, including `test_layers`.
- [ ] **Step 5: Commit** `feat: dump (live graph as sorted JSONL, read-only)`, using `git commit -- <the four files>`.
