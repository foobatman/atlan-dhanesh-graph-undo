# Invariant Checker Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** `uv run check` treats the graph-undo tool as a black box. It runs its CLI commands, reads only the dumps and the undo report, and reports PASS/FAIL/SKIP for invariants 1–8, skipping 7.

**Architecture:**
- A separate top-level package, `src/undo_checker/`, that never imports `graph_undo` or `sqlite3`.
- `model.py` parses dumps and reports.
- `invariants.py` holds pure check functions.
- `run.py` drives `uv run load/apply/dump/undo` with `subprocess` in a workdir.
- `cli.py` prints the results and sets the exit code.

**Tech Stack:** Python ≥ 3.11 stdlib, uv, pytest.

**Spec:** `docs/superpowers/specs/2026-11-19-checker-design.md` (approved). Read it before starting. The rules for each invariant are defined there and not repeated here.

## Global Constraints

- **Worktree:** work in `/Users/dhanesh/workspace/atlan-graph-undo/.claude/worktrees/checker` on branch `checker`. Commit there, and commit only the files each task names (`git commit -- <paths>`).
- **Commands:** every command runs as `uv run …` (`uv run pytest`, `uv run check`). Never call `python` or `pytest` directly.
- **Runtime:** stdlib only.
- **Isolation:** no file under `src/undo_checker/` imports `graph_undo` or `sqlite3`, or opens a `*.db` file. No file under `src/graph_undo/` imports `undo_checker`.
- **Inputs:** text from subprocesses and files is decoded as UTF-8 (`encoding="utf-8"`), never the locale default.
- **Model:**
  - Dump node lines are the lines with `qualified_name`, keyed by `id`.
  - Edge lines are the lines with `from_id`, keyed by `(from_id, to_id, type)`.
  - Authored fields are `description`, `owner`, `tags`. Identity is `id`, `qualified_name`, `type`.
- **Report contract (undo spec):** JSONL on stdout, one object per removed item.
  - Node lines: `kind="node"`, `id`.
  - Edge lines: `kind="edge"`, `from_id`, `to_id`, `type`.
  - Every line: `outcome` ∈ {`restored`, `merged`, `skipped`}. `merged` and `skipped` lines have a non-empty `reason`.
- **Exit codes:** 0 when nothing FAILs. 1 when at least one invariant FAILs. 2 when the run, the guard or the input fails; the message goes to stderr.
- **Timing limit:** `60.0` s, measured over steps 1, 2, 4, 6, 8 and 9.
- **README:** updated in Task 5, in the same commit as the CLI.

## Review Focus

1. **Bad target op:** the `--op` id isn't in `ops.jsonl`, or it isn't a `delete_node`. Expected: exit 2 with `op 'op-9999' not found in <ops>` or `only delete_node ops can be checked (op-0002 is edit_node)`, and no traceback. Tests: `test_slice_unknown_op`, `test_slice_not_delete_node` (Task 4).
2. **Target op on the first line** (op-0001 on seed 42): the slice of ops before it is empty, so step 2 is skipped instead of applying an empty file. Test: `test_prepare_seed42_first_op` (Task 4).
3. **Garbage in the report:** an empty report, a non-JSON line, or a summary line on stdout. Expected: invariant 4 FAILs, with line numbers. No crash, and no exit 2. Test: `test_inv4_garbage_lines` (Task 3).
4. **Undo fails at step 8** (non-zero exit, or the entry point is missing). Expected: exit 2 with `run failed at step 8 (undo): <stderr>`, and the workdir is kept. Test: `test_main_step_failure_keeps_workdir` (Task 5).
5. **Blank lines and non-ASCII names in `ops.jsonl`:** slicing ignores blank lines, keeps each line's bytes exactly, and finds the target by parsed `op_id`. Test: `test_slice_blank_lines_and_unicode` (Task 4).

**Interfaces:**
- Produces, in `undo_checker.model`:
  - `class ModelError(Exception)`
  - `@dataclass(frozen=True) class Dump`. Fields: `text: str`, `nodes: dict[str, dict]` (id → the parsed line), `edges: frozenset[tuple[str, str, str]]`, `parent: dict[str, str]` (child id → parent id, from `contains` edges; if a child has two parents, the first wins and `multi_parent` records it), `multi_parent: frozenset[str]`. Method `names() -> dict[str, list[str]]`: qualified_name → ids, in id order.
  - `parse_dump(text: str) -> Dump`. Raises `ModelError(f"line {n}: …")` on non-JSON, a non-object, a line that is neither a node nor an edge, or a duplicate node id.
  - `@dataclass(frozen=True) class Removed`. Fields: `nodes: dict[str, dict]` (id → D0 line), `edges: frozenset[tuple[str, str, str]]`, `parent0: dict[str, str | None]` (removed id → its D0 parent id).

  - `@dataclass(frozen=True) class ReportLine`. Fields: `lineno: int`, `obj: dict | None`, `error: str | None`.
  - `parse_report(text: str) -> list[ReportLine]`. It never raises. Blank lines are reported as errors (`"blank line"`).
  - `AUTHORED = ("description", "owner", "tags")`, `IDENTITY = ("id", "qualified_name", "type")`
  - `def fields(node: dict, keys) -> tuple`: the values in key order, used for comparisons.
- Test helpers go in `tests/checker/helpers.py`. They are used by Tasks 2–3:
  - `node(id, qn, type="table", tags=(), eff=None, description="", owner="") -> dict`;
  - `dump_text(nodes: list[dict], edges: list[tuple]) -> str`, which serialises the way dump does (sorted keys, compact, nodes sorted by qn, then edges sorted).

### Task 4: Driver (`run.py`)

**Files:**
- Create: `src/undo_checker/run.py`
- Test: `tests/checker/conftest.py`, `tests/checker/test_run.py`

**Interfaces:**
- Produces, in `undo_checker.run`:
  - `class RunError(Exception)`. Its `str` is the stderr message for exit 2.
  - `@dataclass class Target`. Fields: `op_id: str`, `qualified_name: str` (the op's `node`), `pre: list[str]` (raw lines before T, blank lines dropped), `line: str` (T's raw line), `ops_lines: list[dict]` (every op, parsed).
  - `slice_ops(ops_path: Path, op_id: str) -> Target`. It raises `RunError` with exactly:
    - `op '{op_id}' not found in {ops_path}`;
    - `only delete_node ops can be checked ({op_id} is {op})`;
    - `{ops_path}:{n}: not JSON`.
  - `@dataclass class Artifacts`. Fields: `workdir: Path`, `d0, d1, d2, d3, d4: str | None` (dump texts), `report: str | None`, `undo2_stderr: str | None`, `timings: dict[int, float]` (step → seconds).
  - `prepare(seed: Path, ops: Path, target: Target, workdir: Path) -> Artifacts`: steps 1–7. It writes `ops_pre.jsonl`, `ops_target.jsonl`, `D0.jsonl`, `D1.jsonl` and `D2.jsonl` into `workdir`.
  - `finish(art: Artifacts, op_id: str) -> Artifacts`: steps 8–11. It writes `report.jsonl`, `D3.jsonl`, `report2.jsonl`, `undo2.stderr` and `D4.jsonl`.
  - `scenario_seconds(art: Artifacts) -> float`: the sum of `timings` over steps 1, 2, 4, 6, 8 and 9 (missing steps count as 0).
- Both `prepare` and `finish` run each command as `["uv", "run", cmd, *args, "--db", str(workdir / "graph.db")]` with `capture_output=True, encoding="utf-8"`, timed with `time.perf_counter()`.
  - Steps 1–9 must exit 0. Otherwise they raise `RunError(f"run failed at step {n} ({cmd}): {stderr.strip()}")`.
  - After each apply step (2, 4, 6), parse `rejected=(\d+)` from stderr. If it isn't 0, raise `RunError(f"step {n}: apply rejected {k} ops; the scenario is not the one being checked")`.
  - Step 10's exit code is ignored.
  - Step 2 is skipped when `pre` is empty and not recorded in `timings`.
- `tests/checker/conftest.py`:
  - a session fixture `fixture42(tmp_path_factory) -> tuple[Path, Path]` that runs `uv run gen-fixture --seed 42 --out <dir>` and returns `(seed, ops)`;
  - `has_undo() -> bool`, which returns whether `uv run undo --help` exits 0;

  1. `slice_ops`, `prepare`, then `guard`. A guard failure raises `RunError("guard failed: " + first 10 violations joined by "; ")`.

- `RunError`, `ModelError` or a missing seed/ops file → stderr message, exit 2.
- The workdir defaults to `tempfile.mkdtemp(prefix="undo-check-")`. It's removed on success unless `--keep` or `--workdir` was given. Otherwise stderr gets `f"artifacts kept in {workdir}"`.
