# Load Command Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** `uv run load fixtures/seed.jsonl [--db PATH]` builds a fresh SQLite file holding the seed graph in the flag-in-place (B) schema.

**Architecture:**
- `schema.sql` holds the DDL: tables, partial unique indexes and the live / `effective_tags` views.
- `store.py` opens connections and loads a seed into `<db>.tmp` in one transaction, then calls `os.replace` onto `<db>`.
- `cli.py` holds the `load` entry point.

**Tech Stack:** Python ≥ 3.11 stdlib (`sqlite3`, `json`, `argparse`), uv, pytest.

**Spec:** `docs/superpowers/specs/2026-11-19-load-design.md`

## Global Constraints

- **Runtime:** stdlib only.
- **Commands:** every command runs as `uv run …`.
- **Git:** commit directly on `main`.
- **README:** updated in the same task as the CLI change.
- **Entry point:** `[project.scripts] load = "graph_undo.cli:load_main"`. The default `--db` is `graph.db`.
- **Schema version:** `PRAGMA user_version = 1`. `PRAGMA foreign_keys = ON` on every connection.
- **Tags:** stored as compact JSON (`separators=(",",":")`), sorted and unique.
- **Edge ids:** 1…N in file order of edge lines. Every loaded row has `deleted_by IS NULL`.
- **stderr on success:** `loaded <db>: nodes=<n> edges=<m>`, exit 0.
- **stderr on failure:** `<seed path>:<line>: <message>`, exit 1.
- **Out of scope:** `ops` and `removals` tables, crash safety.

## Review Focus

1. **Bad seed over an existing db:** the old db must stay byte-identical and no `.tmp` may remain. Test: `test_failed_load_keeps_existing_db`.
2. **A stale `<db>.tmp` from an earlier aborted run:** load must remove it first and succeed. Test: `test_stale_tmp_is_replaced`.
3. **Edge line before its node lines:** line order must not matter. Test: `test_order_independent`.
4. **Unsorted or duplicate tags in the seed:** they must be stored normalised. Test: `test_tags_normalised`.
5. **A dead row frees its name, edge and parent slot:** the partial indexes must allow a new live duplicate. Test: `test_partial_indexes_ignore_dead_rows`.

### Task 1: Schema and `load_seed`

**Files:**
- Create: `src/graph_undo/schema.sql`
- Create: `src/graph_undo/store.py`
- Test: `tests/test_load.py`

**Interfaces:**
- Produces (`graph_undo.store`):
  - `connect(path: str | Path) -> sqlite3.Connection`, which sets foreign keys on.
  - `load_seed(seed_path: str | Path, db_path: str | Path) -> tuple[int, int]`, which returns `(n_nodes, n_edges)`.
  - `class LoadError(Exception)` with attributes `line: int` and `message: str`, and `str()` of `"<line>: <message>"`.

- [ ] **Step 1: Write the failing tests** in `tests/test_load.py`. Seed 42 comes from `generate_seed(42)` and `serialize`, written to `tmp_path`.
  - `test_counts`: `load_seed` returns `(2503, 2801)`.
  - `test_round_trip`: `live_nodes` rows equal the seed nodes, with tags parsed. `live_edges` rows without `id` equal the seed edges, as multisets.
  - `test_all_live`: there are no rows with `deleted_by IS NOT NULL`.
  - `test_edge_ids_file_order`: the edge ids are `1..2801`, in seed edge order.
  - `test_user_version`: equals `1`.
  - `test_effective_tags`: for every node, the view equals the sorted union of its own tags and its ancestors' tags, computed in Python from the seed.
  - `test_tags_normalised`: a node with `["pii","gold","pii"]` is stored as `'["gold","pii"]'`.
  - `test_order_independent`: a small seed with an edge line first loads fine.
  - `test_rejects` is parametrised. Each case writes a small seed and asserts `LoadError.line` equals the bad line, and that neither `<db>` nor `<db>.tmp` exists afterwards. The cases are:
    - bad JSON;
    - a missing key;
    - an extra key;
    - `tags` not a list;
    - a non-string field;
    - an unknown node type;
    - an unknown edge type;
    - a duplicate id;
    - a duplicate `qualified_name`;
    - an edge to an unknown id;
    - a self-loop;
    - a duplicate edge;
    - a second `contains` parent;
    - a `contains` edge that breaks type order (table → table, and schema → column).
  - `test_failed_load_keeps_existing_db`: load good, then bad, onto the same path. The file bytes are unchanged.
  - `test_reload_replaces`: load seed A, then seed B, onto the same path. Only B's nodes are present.
  - `test_deterministic`: two loads of the same seed give equal `SELECT *` contents for `nodes` and `edges`.
  - `test_stale_tmp_is_replaced`: write garbage to `<db>.tmp`, then load. The load succeeds and no tmp remains.
  - `test_partial_indexes_ignore_dead_rows`: after a load, set `deleted_by='op-x'` on a node and on its contains edge. Inserting a new node with the same `qualified_name`, the same contains edge, and a new parent edge for the same child all succeed. Inserting a duplicate *live* name raises `sqlite3.IntegrityError`.

- [ ] **Step 2: Run** `uv run pytest tests/test_load.py -q`. Expected: collection error, with no `graph_undo.store`.

- [ ] **Step 3: Implement** `schema.sql` exactly as in the spec, plus the `effective_tags` view. The view is a recursive CTE `anc(node_id, anc_id)` seeded with `(id, id)` from `live_nodes`. It walks up through `live_edges` of type `contains` and selects `json_group_array(DISTINCT tag)` from `json_each(anc.tags)`, ordered. Nodes with no tags still get `[]`.

  Also implement `store.py`:
  1. Parse all lines and validate the keys and types in Python, attaching line numbers.
  2. Build `<db>.tmp` and apply the schema.
  3. Insert the nodes, then the edges, each with its line known.
  4. Check `contains` type order in Python.
  5. Map an `IntegrityError` to a `LoadError` for the current line.
  6. Commit, close, then `os.replace`. On any failure, remove the tmp file.

- [ ] **Step 4: Run** `uv run pytest -q`. Expected: all pass.

- [ ] **Step 5: Commit** `feat: load seed.jsonl into SQLite (flag-in-place schema)`.
