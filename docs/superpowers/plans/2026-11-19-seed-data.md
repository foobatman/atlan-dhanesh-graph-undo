# Seed Data Generator Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** `uv run gen-fixture --seed 42` writes a deterministic `fixtures/seed.jsonl` (~5,000 nodes + edges) shaped for the later undo scenario.

**Architecture:** A uv-managed package `graph_undo`. A pure function `generate_seed(seed)` builds nodes and edges in memory from one `random.Random(seed)`. A separate `serialize` turns them into JSONL text, and `main` is the CLI entry point. Tests assert the spec's structural properties against `generate_seed(42)`.

**Tech Stack:** Python ≥ 3.11 (stdlib only at runtime), uv, pytest (dev group).

**Spec:** `docs/superpowers/specs/2026-11-19-seed-data-design.md`

## Global Constraints

- Every command runs as `uv run …`. Never call `python`/`pytest` directly or activate a venv.
- No runtime dependencies. pytest only in `[dependency-groups] dev`.
- All randomness from a single `random.Random(seed)`. No `uuid4()`, `time`, or iteration over unordered `set`s.
- Node fields exactly `id, qualified_name, type, description, owner, tags`. Edge fields exactly `from_id, to_id, type`. Edge `type` ∈ {`contains`, `references`}.
- Node `type` values: `connection, database, schema, table, column`.
- Shape: 2 connections × 2 databases × 3 schemas. Normal schemas have 15–21 tables, tables have 5–12 columns. One big schema has ~62 tables and a subtree ≥ 550 nodes.
- Totals: ~2,400–2,600 nodes, contains = nodes − 2, ~300 table→table references (≥ 60 crossing the big schema, both directions), total lines 4,500–5,500.
- Tags vocabulary `pii, gold, silver, finance, marketing, certified, deprecated`. 0–2 per node, sorted, unique.
- Owners: fixed list of ~8 names. Description: non-empty template.
- Serialisation: `json.dumps(obj, sort_keys=True, separators=(",", ":"))`, UTF-8, `\n`, trailing newline.
- Order: nodes in DFS pre-order, then contains edges in the same order, then references sorted by `(from qualified_name, to qualified_name)`.

## Review Focus

1. `--out` pointing at a directory that doesn't exist → it is created, not a crash. (Task 4 test `test_main_creates_out_dir`)
2. Re-running into the same dir → file overwritten, not appended. (Task 4 test `test_main_overwrites`)
3. Seed `0` and very large seeds (`2**64`) → valid graph, still deterministic. (Task 4 test `test_unusual_seeds`)
4. A qualified-name component containing `/` or whitespace would break path semantics → names match `^[a-z0-9_]+$`. (Task 1 test `test_name_components_clean`)
5. A child tagged with a tag its ancestor already has → allowed and present at least once (exercises union dedupe later). (Task 2 test `test_redundant_inherited_tag_exists`)

def test_contains_is_tree(graph):

TAGS = {"pii", "gold", "silver", "finance", "marketing", "certified", "deprecated"}

def _schemas_by_size(graph):

    ch = children(edges)
    return sorted((subtree_size(n["id"], ch), n["id"]) for n in nodes if n["type"] == "schema")

def test_big_schema(graph):

    assert sizes[-1][0] >= 550
    assert sizes[-2][0] < 500                      # exactly one big schema

def test_node_totals(graph):

def test_tags_valid(graph):
    nodes, _ = graph
    for n in nodes:
        assert set(n["tags"]) <= TAGS and len(n["tags"]) <= 2
        assert n["tags"] == sorted(set(n["tags"]))

def test_inheritance_is_exercised(graph):
    nodes, _ = graph
    upper = [n for n in nodes if n["type"] in ("database", "schema")]
    assert sum(bool(n["tags"]) for n in upper) >= 0.2 * len(upper)

def test_redundant_inherited_tag_exists(graph):
    nodes, edges = graph
    ids, parent = by_id(nodes), {e["to_id"]: e["from_id"] for e in edges if e["type"] == "contains"}
    def ancestor_tags(i):
        out = set()
        while i in parent:
            i = parent[i]; out |= set(ids[i]["tags"])
        return out
    assert any(set(n["tags"]) & ancestor_tags(n["id"]) for n in nodes)

def test_authored_fields_present(graph):
    nodes, _ = graph
    assert all(n["description"] and n["owner"] for n in nodes)
    assert len({n["owner"] for n in nodes}) >= 5

def _refs(graph):
    return [e for e in graph[1] if e["type"] == "references"]

def test_references_shape(graph):
    nodes, _ = graph
    ids, refs = by_id(nodes), _refs(graph)
    assert 250 <= len(refs) <= 350
    assert all(ids[e["from_id"]]["type"] == ids[e["to_id"]]["type"] == "table" for e in refs)
    assert all(e["from_id"] != e["to_id"] for e in refs)
    assert len({(e["from_id"], e["to_id"]) for e in refs}) == len(refs)

def test_references_cross_big_schema(graph):
    nodes, edges = graph
    big_id = _schemas_by_size(graph)[-1][1]
    inside = set()
    stack, ch = [big_id], children(edges)
    while stack:
        i = stack.pop(); inside.add(i); stack.extend(ch.get(i, []))
    refs = _refs(graph)
    inbound = [e for e in refs if e["to_id"] in inside and e["from_id"] not in inside]
    outbound = [e for e in refs if e["from_id"] in inside and e["to_id"] not in inside]
    assert len(inbound) + len(outbound) >= 60 and inbound and outbound

def test_edge_order(graph):
    nodes, edges = graph
    qn = {n["id"]: n["qualified_name"] for n in nodes}
    types = [e["type"] for e in edges]
    assert types == sorted(types)                 # all contains, then all references
    keys = [(qn[e["from_id"]], qn[e["to_id"]]) for e in _refs(graph)]
    assert keys == sorted(keys)

def test_total_lines(graph):
    nodes, edges = graph
    assert 4500 <= len(nodes) + len(edges) <= 5500

def test_deterministic_bytes():
    assert serialize(*generate_seed(42)) == serialize(*generate_seed(42))
    assert serialize(*generate_seed(42)) != serialize(*generate_seed(43))

def test_serialize_format():
    nodes, edges = generate_seed(42)
    text = serialize(nodes, edges)
    lines = text.split("\n")
    assert text.endswith("\n") and lines[-1] == ""
    assert lines[0] == json.dumps(nodes[0], sort_keys=True, separators=(",", ":"))
    parsed = [json.loads(l) for l in lines[:-1]]

def test_main_creates_out_dir(tmp_path, capsys):
    out = tmp_path / "a" / "b"
    assert main(["--seed", "7", "--out", str(out)]) == 0
    assert (out / "seed.jsonl").read_text() == serialize(*generate_seed(7))
    assert "nodes" in capsys.readouterr().err

def test_main_overwrites(tmp_path):
    main(["--seed", "1", "--out", str(tmp_path)])
    main(["--seed", "2", "--out", str(tmp_path)])

def test_unusual_seeds():
    for s in (0, 2**64):
        a, b = serialize(*generate_seed(s)), serialize(*generate_seed(s))

                       capture_output=True, text=True)

    assert (tmp_path / "seed.jsonl").read_text() == serialize(*generate_seed(42))
